One-line: KPI/metric block — uppercase label, large tabular value, muted caption.

```jsx
<StatCard label="Total Audience" value="745.9M" caption="Across all platforms" highlight />
<StatCard label="Platforms Tracked" value="21" caption="Live metrics" icon={<DbIcon/>} />
```

`highlight` colors the value purple — reserve for the single leading metric in a row (Purple Budget Rule).
