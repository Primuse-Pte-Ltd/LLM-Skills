One-line: Kisum's primary action button — purple fill for the single primary action, outline/secondary/ghost for the rest.

```jsx
<Button variant="primary">New Booking</Button>
<Button variant="outline" pill>Send Enquiry</Button>
<Button variant="ghost" size="sm">Details</Button>
<Button variant="destructive" size="sm">Unpublish</Button>
```

Variants: `primary` (purple), `outline` (purple border/text), `secondary` (gray border), `ghost` (text only), `destructive` (red). Sizes `sm|md|lg`. `pill` for branded round CTAs; `full` to span width; `iconLeft`/`iconRight` for icons. Respect the Purple Budget Rule — one purple CTA per view.
