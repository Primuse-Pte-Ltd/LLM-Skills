One-line: calendar-leaf date — teal caps month over a bold day.

```jsx
<DateChip month="OCT" day="24" />                 {/* discovery card, grey leaf */}
<DateChip month="NOV" day="02" variant="glass" /> {/* over event imagery */}
<DateChip month="DEC" day="12" variant="plain" /> {/* mobile upcoming list */}
```

Month is always 3-letter uppercase in teal (`JAN…DEC`, `TBA` if unknown); day is 2-digit (`--` if unknown). The leaf metaphor is a brand signature — use it instead of inline "Oct 24" on cards.
