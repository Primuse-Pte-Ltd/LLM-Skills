One-line: Icon-only button for dense management actions (edit, delete, overflow, notifications).

```jsx
<IconButton label="Notifications"><BellIcon/></IconButton>
<IconButton variant="tint" label="Save"><BookmarkIcon/></IconButton>
<IconButton variant="solid" label="Add"><PlusIcon/></IconButton>
```

Variants: `ghost` (muted, subtle hover), `tint` (purple on tint), `solid` (purple fill). `size` in px (default 40).
